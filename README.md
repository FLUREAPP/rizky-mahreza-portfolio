# Rizky Mahreza — Executive HSE Portfolio

Single-page executive portfolio for Rizky Mahreza, Senior HSE Specialist.

## Stack

- React + TypeScript + Vite
- Plain CSS with responsive design tokens
- Data-driven content model
- No runtime dependency on third-party UI libraries

## Local development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run typecheck
npm run build
```
